# Documents

These documents were produced in September 2026 while the product was still
called by its working name **zhi**. The product is now **fathom**. Read `zhi` as
`fathom` throughout: the command (`fathom check`), the workspace directory
(`.fathom/`), the lockfile (`fathom.lock`), schema keywords (`x-fathom-*`),
trailers (`Fathom-Snapshot:`) and API groups (`fathom.dev/v1`). The documents are
kept verbatim as the record of the decision.

- `brief.html`: the research and design brief; open it in a browser.
- `design/design.md`: Design v2, the current plan. `design-v1-before-critique.md`,
  `proposals/`, `judgements.json` and `critiques.json` are the panel material it
  came from.
- `research/landscape-report.md`: the landscape synthesis with sources.
- `research/current-codebase-audit.md`: what carries over from the old zhi codebase.
- `research/briefs/`: the seventeen research briefs the synthesis was built from.
